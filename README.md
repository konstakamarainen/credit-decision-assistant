# Luottopäätösavustaja

Konseptiprototyyppi Luottoriskit.fi-palvelulle. Frontend-only React-demo, joka auttaa arvioimaan asiakkaan luottoriskiä suhteessa suunniteltuun kauppaan.

## Käynnistys

```bash
npm install
npm run dev
```

Avaa selain osoitteessa, jonka Vite tulostaa (yleensä `http://localhost:5173`).

## Teknologia

- React + TypeScript + Vite
- Tailwind CSS
- Ei backendia, API-kutsuja tai autentikointia
